## 🛠 Login Fail Ho Raha Hai? Yeh Check Karein

| Problem | Solution |
|---|---|
| Incorrect password error | Caps Lock check karein, password reset use karein |
| Page load nahi ho raha | Network switch karein, cache clear karein |
| OTP nahi aa raha | 2-3 min wait, resend try karein, registered number verify karein |
| Account locked lag raha hai | Third-party "support" number pe call na karein — scam pattern hai |

## 💰 Withdrawal Process — General Steps

1. Account section mein **Withdraw/Cashout** option dhundo
2. Withdrawal amount enter karo (minimum limit check karo)
3. Bank/UPI details verify karo — pehli baar add kar rahe ho to KYC step aa sakta hai
4. Request submit karo
5. Confirmation ka wait karo — processing time platform aur payment method pe depend karta hai

**Withdrawal delay ho to yeh check karo:**
- KYC/verification pending to nahi hai
- Minimum withdrawal amount meet ho raha hai ya nahi
- Payment details correctly saved hain ya nahi
- Platform ke stated processing window ke andar ho (agar window cross ho gaya ho to hi support contact karo)

## ☎️ Customer Care & Support

Support se contact karne se pehle:

- ✅ Sirf app/website ke andar diye gaye **official support/help section** use karo
- ✅ Registered mobile number se hi contact karo agar call/chat option ho

- ❌ Agar koi "agent" pehle paisa maang raha hai processing ke naam pe, wahin samajh jao ki scam hai
